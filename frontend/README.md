# Container Control Web

React + TypeScript app built with Vite, Tailwind CSS, and shadcn/ui.

The dark dashboard includes a local demo container with start/stop controls and a stop confirmation dialog. State resets on reload; no real containers are created.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

The Railway API integration has not been implemented yet.
